I wish it was easier to make “self editing” HTML files. I should be able to have a single HTML file, open it, put text in the inputs/textareas or wherever, save it, and the HTML file should update and have the content saved.

This is possible but only with a server. Chrome does have access to the native file system, but not on ‘file://‘ so you still need a server.
